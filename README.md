# SECRET BOX — Home Assistant automation

Проект автоматики гроубокса SECRET BOX размером 160 × 60 × 60 см.

## Зафиксированные требования
- Управление через Home Assistant; физические ручки/потенциометры не используются.
- Контроллер: Raspberry Pi 5, 2 GB RAM.
- Четыре вентилятора циркуляции: два верхних и два нижних, зоны регулируются независимо.
- Один светильник: Just Grow X Space 150W.
- Вытяжка: SENSDAR SE-A125-H02, EC.
- Угольный фильтр: CarbonActive HomeLine Filter 300Z, Ø125 mm.
- Насос: 12 V DC.
- Датчик климата пока оставляем первоначально выбранный Wiren Board WB-MSW v.4 (температура/влажность; набор измеряемых параметров зависит от комплектации).
- Измерение CO₂ отдельным комбинированным датчиком отложено.

## Архитектура
- Home Assistant работает на Raspberry Pi 5.
- USB–RS485 адаптер соединяет Raspberry Pi с шиной Modbus RTU.
- На общей шине планируются WB-MAO4, WB-MSW v.4 и релейный модуль; каждому устройству назначается уникальный Modbus-адрес, параметры последовательного порта должны совпадать.
- WB-MAO4 управляет совместимыми входами 0–10 V вытяжки и светильника после проверки схемы/распиновки конкретных устройств.
- Релейный модуль: включение питания светильника 230 V и насоса 12 V; два канала остаются резервными.
- Для четырёх 4-pin PWM вентиляторов нужен отдельный контроллер с двумя независимыми PWM-каналами, совместимый с Home Assistant. Его модель и электрическое согласование пока НЕ утверждены.

## Статус
Это зафиксированная проектная спецификация, а не утверждение, что схема уже собрана или проверена. Перед закупкой и монтажом требуется подтвердить PWM-контроллер, питание 12 V по суммарному току, а также электрическую совместимость входов 0–10 V и релейные нагрузки.
